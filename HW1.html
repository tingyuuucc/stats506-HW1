Q3:Happy Numbers

a. Write a function nextHappy() that given a positive integer, computes the next value in the happy-number sequence. Be sure to provide a reasonable error on an invalid input. Be sure to document your function.

# compute the next value in a happy number sequence
nextHappy <- function(n) {
  # check that n is a single positive integer
  if(length(n) != 1 || is.na(n) || n <= 0 || n != floor(n)) {
    stop("input must be a positive integer")
  }
  
  # split n into individual digits
  digits <- as.numeric(strsplit(as.character(n), "")[[1]])
  
  # return the sum of the digits
  sum(digits^2)
}

b.Create a function happySequence() that returns the sequence beginning at a given number. Use your nextHappy() function to perform the calculation. Be sure to provide a reasonable error on an invalid input. Be sure to document your function.

# generate a happy number sequence
happySequence <- function(n) {
  # check that n is a single positive integer
  if(length(n) != 1 || is.na(n) || n <= 0 || n != floor(n)) {
    stop("input must be a positive integer")
  }
  # start the sequence
  sequence <- n
  
  # continue until the sequence reaches 1 or enters a cycle
  while (tail(sequence, 1) != 1) {
    # calculate the next value
    next_value <- nextHappy(tail(sequence, 1))
    #check the next value has already appeared
    if(next_value %in% sequence) {
      return(list(
        sequence = sequence,
        isHappy = FALSE
      ))
    }
    # add the next value
    sequence <- c(sequence, next_value)
  }
  # return the sequence and TRUE if reaches 1
  return(list(
    sequence = sequence,
    isHappy = TRUE
  ))
}
